## Projects

| Project | What it does | Stack | Key result |
|---|---|---|---|
| [**Revenue-Forecast-7d**](https://github.com/Chuchman-Dima/Revenue-Forecast-7d) | Forecasts 7-day revenue of ~1.6M users from first-24h behavior, so channels can be evaluated 6 days earlier | Python, CatBoost, LightGBM, SHAP | Channel WAPE 10.6% (vs. 18.1% baseline), revenue bias −0.01% |
| [**E-Commerce-Olist**](https://github.com/Chuchman-Dima/E-Commerce-Olist) | Analysis of how delivery delays affect customer satisfaction (~99K orders), SQL pipeline + dashboard | PostgreSQL, Pandas, Power BI | Review score drops from 4.29 to 1.70 for 7+ days late |
| [**MarketScout**](https://github.com/Chuchman-Dima/MarketScout) | Used car price estimation on ~100K listings: FastAPI backend, Streamlit app, Power BI dashboard | LightGBM, Optuna, FastAPI, Docker | MAE $1,921, MAPE 15.75%, R² 0.92 |
| [**Home-Credit-Default-Risk**](https://github.com/Chuchman-Dima/Home-Credit-Default-Risk) | Credit scoring from 7 relational tables (~58M rows), ~172 engineered features | LightGBM, scikit-learn, SHAP | ROC-AUC 0.769 |
